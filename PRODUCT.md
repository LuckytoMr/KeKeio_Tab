# Product

## Register

product

## Users

Power users who live in the browser and want a fast, private, highly customizable new tab page. They add many internal tools, cloud services, router/admin pages, development links, and personal resources, often across more than one browser or device.

## Product Purpose

KeKeIO Tab is a local-first browser new tab extension. It replaces the default new tab with a calm, efficient dashboard for search, navigation, wallpaper rotation, and personal configuration. Success means the new tab opens instantly offline, supports dense personal navigation, and gives advanced users optional sync without uploading private images.

## Brand Personality

Quiet, precise, configurable.

## Anti-references

- Marketing landing pages inside the extension.
- Heavy card grids, oversized hero sections, decorative blur blobs, or one-note purple/blue gradients.
- Search hijacking, forced redirects, affiliate injection, or misleading "free wallpaper" behavior.
- Interfaces that feel like a clone of another navigation product; the layout can be familiar, but the visual language must be original.

## Design Principles

- The new tab is a tool surface, not a sales page.
- Local state wins: the page must be useful before network, login, or sync.
- Advanced features stay discoverable but do not interrupt the primary open-search-click workflow.
- Privacy boundaries must be visible in product behavior, not only written in policy text.
- Every feature should preserve a fast first paint and low memory footprint.

## Accessibility & Inclusion

Target WCAG 2.1 AA for text contrast and keyboard access. Respect reduced motion. Avoid relying on color alone for state. All core actions must be reachable by keyboard.
